BJT Amplifier: Choosing Replacement BJTs

Datasheet Table · Select a Faulty Transistor · Pick the Best Substitute

Find an appropriate substitute for each transistor below. Table 1 draws 6 random candidates from a 26-part pool each time you pick a transistor to replace — 2 TO-92, and 1 each of TO-72/TO-126/TO-220/TO-3 — so the options are different every attempt. You can shortlist more than one candidate — click a row to add it, click again to remove it — then press Check. Work through the criteria in this order — a later one only matters once every earlier one is satisfied:

  1. Polarity must match (N/P)
  2. Case should ideally match (pins should line up)
  3. Specs must match or exceed, in this order: VCE, IC, Power, VCB
  4. Use — the closest matching application
  5. Beta — closest current-gain range
  6. FT — closest transition frequency
