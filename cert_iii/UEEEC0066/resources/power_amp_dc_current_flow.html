Measured (as on the CRO)

The output limits are set so the biggest output matches the 13.5 V peak-to-peak measured on the class CRO. On the negative half the 741 has to sink R4's current through D1 (and on the positive half source R5's), as well as drive an output transistor's base, so it runs out of current before the output reaches the rails.

    The numbers come from a model with typical part values (D1 ≈ 0.72 V at 30 mA, VBE ≈ 0.55 V at 10 mA, β = 50, an ideal 741 drawing 1.7 mA). A real board will read a little differently, but every reading should move the same way when a switch changes.
