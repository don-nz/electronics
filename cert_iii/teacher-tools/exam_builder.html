    Spreadsheet format

    One question per row, with these column names in the first row. Save as .xlsx or CSV (Excel and LibreOffice both do this). Only question is required.

    ColumnMeaning
    sectionQuestions are drawn per section.
    pickHow many items to draw from the section (any row of the section).
    groupSame value = one related set, drawn together; its diagram prints once above them.
    typemc multi tf short long calc fill stem (stem = a group's shared intro/diagram).
    marksWhole number (defaults: mc/tf/short 1, long 2, calc 3, fill = blanks).
    questionText. <sub> <sup> <b> <i> allowed. Fill: [[answer]] or [[mean/average]].
    a–fMultiple-choice options.
    answermc: letter or option text · multi: A,C · tf: true/false · others: model answer.
    explanationWorking / marking notes (guide only).
    diagramInline <svg>…</svg>, or an image path / URL / data URI.
    linesAnswer lines to print (short/long).
    idOptional label, e.g. R-014.
