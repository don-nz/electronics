This is the circuit Z = A·B·C + B·C built on a breadboard, but it has one fault. Find it the way you would on the bench:
  1. Try the A, B and C switches and compare the logic indicator with the truth table. Which settings give the wrong Z?
  2. Tap any hole or IC pin to touch the logic probe on it (tap the same spot, or the probe, to lift it off): HI lights for a 1, LO for a 0, and neither lights if there is no valid level there. That is a floating point, and a TTL input left floating behaves as HIGH.
  3. Compare each reading with the expected level on the circuit diagram. Work back from Z to the first point that is wrong. If a gate's inputs and power pins are right but its output is wrong, suspect the gate. If one of its inputs is wrong, follow the wire back.
  4. Choose the fault type and where it is, then Check. New Fault gives you another one.
The wire colours here are just jumper colours. They don't show logic levels, so only the probe can tell you what's on a wire.
